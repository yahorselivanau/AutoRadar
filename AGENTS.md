# AGENTS.md

## Цель проекта

Создать mobile-first AI-агрегатор автозапчастей для Беларуси. Главный
приоритет — стабильно получать и показывать реальные предложения из нескольких
источников.

## Контекст

Читайте только документы, относящиеся к текущей задаче:

- продукт и сценарии: `docs/PRD.md`;
- технические решения: `docs/ARCHITECTURE.md`;
- интерфейс: `docs/DESIGN_SYSTEM.md`;

Прямая инструкция владельца проекта в чате имеет приоритет. Не обновляйте
документы и не создавайте новые отчёты, если задача этого не требует.

## Разработка

- Используйте `pnpm`, TypeScript strict и существующую структуру Turborepo.
- Для Next.js используйте App Router и Server Components по умолчанию.
- Валидируйте внешние данные существующими Zod-схемами.
- Переиспользуйте текущие компоненты и доменные контракты.
- Не добавляйте преждевременную инфраструктуру и абстракции.
- Не коммитьте секреты.

## Адаптеры

- Не выдумывайте endpoint, параметры, селекторы и возможности источника.
- Используйте порядок: HTTP/URL → SSR HTML → публичный JSON/XHR → Playwright.
- При изменении адаптера обновляйте только его `DISCOVERY.md` и fixtures,
  необходимые для воспроизводимости.

## Проверка

Запускайте минимальный релевантный набор из `pnpm lint`, `pnpm typecheck`,
`pnpm test`, `pnpm build` и source-specific smoke-команд. В итоговом ответе
кратко укажите изменённое, выполненные проверки и то, что не удалось проверить.
