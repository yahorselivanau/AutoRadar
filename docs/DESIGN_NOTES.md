# Design notes

Референсы были сведены к трём продуктовым принципам:

1. **Чат как стартовая точка.** Из Nolla взяты спокойная композиция, крупный
   prompt и лёгкая боковая навигация, без фоновой lifestyle-фотографии.
2. **Выдача как рабочий инструмент.** Из Daydream взяты разговорный контекст,
   chips и карточная выдача; из Idealo — приоритет цены, наличия и источника,
   но без перегруженной таблицы.
3. **Mobile-first continuity.** Один и тот же запрос сохраняет контекст между
   чатом, подтверждением и deep-link выдачей. На мобильном нет горизонтальных
   таблиц или постоянного filter rail.

Текущий визуальный язык следует `DESIGN_SYSTEM.md`: тёплая бумага, белые
поверхности, Inter, Radar Blue только для действия и поиска, семантические
цвета только для состояний.
