# Inter

Self-hosted official **Inter 4.1** variable web fonts from
[`rsms/inter`](https://github.com/rsms/inter/releases/tag/v4.1).

- `InterVariable.woff2`: normal, weight 100–900, optical size 14–32.
- `InterVariable-Italic.woff2`: italic, weight 100–900, optical size 14–32.
- Both files include the official Latin and Cyrillic glyph sets.
- Runtime loading is local through `next/font/local`; no font CDN is used.
