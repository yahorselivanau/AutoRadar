Дата публичного исследования: 28 июля 2026.

## 3. Что подтверждено публичными страницами

### Bamper

Публичная выдача показывает:

- OEM-поле;
- автомобильные параметры;
- новые/б/у;
- цену;
- город;
- продавца/рейтинг;
- карточки предложений.

Пример OEM URL был найден в формате:

```text
/zchbu/originalnum_<OEM>/
```

Это только исследовательская подсказка. Codex обязан проверить актуальное формирование URL и не строить адаптер на одном примере.

### ARMTEK

Публичный сайт заявляет:

- подбор по VIN;
- поиск по номеру;
- подбор по марке/модели;
- оригиналы и аналоги.

Официальная оптовая страница сообщает, что прайс-лист и web-services доступны после заключения договора. Значит scraper является только временным MVP-адаптером.

### AV-parts

Сайт прямо называет себя агрегатором и показывает каталог с миллионами позиций. Результат может уже объединять предложения магазинов. Необходимо:

- сохранять `source = av-parts`;
- сохранять фактического продавца, если он виден;
- не выдавать одинакового продавца дважды, если он также подключён напрямую;
- не заявлять, что AV-parts является отдельным складом.

### Remzona

Публичный автоматический доступ к сайту может быть ограничен. Codex должен выполнить discovery в интерактивном браузере, проверить robots/условия и прекратить интеграцию, если публичный поиск нельзя воспроизвести без обхода защиты.

## 5. Общие ограничения

- Не обходить CAPTCHA.
- Не маскировать автоматический трафик под пользователя для обхода запретов.
- Не использовать чужие аккаунты.
- Не собирать телефоны и персональные данные сверх того, что нужно для карточки предложения.
- Не копировать изображения в собственное хранилище в MVP; использовать внешнюю ссылку только если это допустимо.
- Не загружать весь каталог.
- Ограничить результат несколькими наиболее релевантными страницами/предложениями.
- Отправлять понятный User-Agent с контактом проекта, когда это технически и юридически уместно.
- Добавить страницу для владельцев источников с возможностью связаться и отключить интеграцию.
