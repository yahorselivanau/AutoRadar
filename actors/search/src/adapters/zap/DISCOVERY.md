# Zap.by discovery

Проверено 30 июля 2026 года по материалам владельца проекта и точечным
публичным HTTP-запросам.

## Правила доступа

Источник истины для разработки — переданный локальный `robots.txt`
(`sha256: 5afd28a009eb910e9e3d3e5a03c7c49763c761b0d76288dc99a61eff30001046`).
В группе `User-agent: *` нет `Disallow`; маршруты, содержащие `search`, и
query-параметры явно разрешены. Фрагмент правил сохранён в
`fixtures/robots.txt`. Указанная там карта сайта
`https://zap.by/sitemap.xml` отвечает `200` и содержит 64 дочерние карты.

Адаптер ограничивает навигацию подтверждёнными публичными маршрутами:

- `/carparts` и дочерние SSR-страницы;
- `/carparts/search/{query}` для номера и текста;
- `/{brand}/{article}` для публичной карточки;
- `/index.php?route=catalog/parts/choice3d` для выбора модификации.

Личные кабинеты, VIN и checkout не используются. Между HTTP-запросами
выдерживается настраиваемый интервал.

## Подтверждённые контракты

Переданная страница `maslyanyi-nasos`
(`sha256: 99aa364e7457538303f3d9670c4b8abc0946fee107e2119d8198d1a812a0c6b6`)
является SSR-каталогом:

- canonical:
  `/carparts/bmw/3-f30-f80/320-i-59409/maslyanyi-nasos`;
- `section_id = 525`, `type_id = 59409`;
- скрытые выбранные ID автомобиля:
  `ses_sel_manufacturer=16`, `ses_sel_model=9831`,
  `ses_sel_type=59409`; адаптер использует их как резерв к inline-переменным;
- 4 карточки `.product-block`;
- товарная ссылка `a.td-info-name`;
- цена в `data-price`, наличие в `.avail`, срок в `.td-delivery`;
- поиск категории:
  `/info/search?car_type_id=59409` (не нужен текущему runtime);
- следующая страница загружается тем же URL с `page` и `infinite=1`.

`common.js` подтверждает основной search URL и vehicle picker.
`live_search.js` подтверждает autocomplete, но он не нужен адаптеру.
`webservices.js` подтверждает динамические складские цены; текущие SSR
карточки уже содержат нормализуемую минимальную цену, наличие и срок.

Прямой HTTP-запрос `/carparts/search/7700274177` отвечает `200` и отдаёт
SSR-кандидатов. Первая публичная карточка OEM содержит SSR-аналоги и цены,
поэтому Playwright для runtime не требуется.

## Стратегия

1. Для номера детали или запроса без автомобиля открыть прямой SSR-поиск.
2. Перейти в первую подтверждённую карточку и разобрать SSR-предложения.
3. Для запроса автомобиля пройти SSR-лестницу
   `марка → модель → категория`.
   Локализованное написание марки сопоставляется с фактической латинской
   подписью каталога через общий versioned-справочник; неизвестная марка не
   угадывается.
4. Если заданы двигатель и точная модификация, получить URI через
   `choice3d` и поставить точную страницу выше model-family fallback.
5. Обогатить ограниченное число кандидатов публичными карточками, затем
   консервативно проверить название, применимость и ограничения.

Предложение без доказательства совместимости с переданным автомобилем
остаётся `possible`; соседние товары с другим названием детали отбрасываются
даже при поиске по OEM.

## Transport budget

Один публичный HTTP-запрос получает не менее 15 секунд. Это соответствует
архитектурному диапазону 15–20 секунд и покрывает наблюдённую задержку
Vercel → Zap.by, при которой прежний лимит 10 секунд завершал рабочий маршрут
ошибкой до ответа источника.
