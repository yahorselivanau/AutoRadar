# Remzona.by discovery

Проверено 30 июля 2026 года по существующим воспроизводимым fixtures и
публичному `robots.txt`.

## Разрешённый контракт

- Runtime использует идентифицируемый `AutoRadar` User-Agent, который
  подчиняется группе `User-agent: *`.
- Общий поиск выполняется `POST /` без query string с наблюдёнными полями
  `typerequest=search&q=<query>`. Запрещённый robots маршрут `/search` не
  вызывается.
- Карточки и каталоги загружаются только по HTTPS-ссылкам, возвращённым самим
  `remzona.by`; внешние host отклоняются.
- Между запросами выдерживается интервал, HTTP 429/Cloudflare преобразуются в
  типизированную ошибку. Playwright используется только как отключаемый
  fallback, когда разрешённый SSR-каталог не содержит цены.

## Поиск и доказательства

- По тексту сначала выбирается точное название категории, затем выполняется
  существующая лестница `категория → марка → модель`.
- Локализованное написание марки сопоставляется с фактической латинской
  подписью каталога через общий versioned-справочник; неизвестная марка не
  угадывается.
- По артикулу используется исходная строка пользователя. Подсказка товара
  принимается только при точном совпадении нормализованного номера из
  структурированного `data-choose`.
- Этот номер переносится в предложение как `rawPartNumber` и
  `normalizedPartNumber`; только такое совпадение получает `confirmed`.
  Номер из свободного заголовка не повышается до подтверждённого.
- Цена читается по порядку: JSON-LD, microdata, `data-price`/`data-cost`,
  проверенный BYN DOM. Валюта не угадывается.
- Подтверждённая карточка без цены остаётся реальным предложением с
  необязательным `priceAmount`; отсутствие цены само по себе не превращает
  весь источник в ошибку.

## Ограничения

- VIN и OEM-применимость источник не подтверждает.
- Для поиска по артикулу пока загружается первая точная товарная подсказка;
  разные бренды с одним номером не объединяются как один товар.
- Применимость по автомобилю остаётся `possible` до структурированного
  подтверждения источником.
